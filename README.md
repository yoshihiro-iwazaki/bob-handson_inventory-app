# bobathon-inventry-app-v2

IBM Bob ハンズオン用リポジトリです。

## 📦 構成

- **[`inventory-app/`](./inventory-app)** 
  - 本リポジトリの**コード本体**です。ハンズオンの題材となる在庫管理アプリケーション（Flask + pandas）が入っています。セットアップ手順・機能詳細は [`inventory-app/README.md`](./inventory-app/README.md) を参照してください。
- **ハンズオンのシナリオ手順** 
  👉 **https://yoshihiro-iwazaki.github.io/bob-handson_inventory-app/instruction.html**

## 🎓 ハンズオンシナリオ概要

> `instruction.html` の各シナリオで、AI駆動開発において何を学べるかを1行でまとめたもの。

| シナリオ | AI駆動開発で学べること |
|---|---|
| シナリオ①【ONBOARD（導入）】 AGENTS.md 作成 | `/init` 一つで既存プロジェクトをAIに理解させ、以降のすべての対話で使えるプロジェクトコンテキストを用意する方法を学ぶ。 |
| シナリオ②【GOVERN（規約適用）】 コーディング規約から、カスタム・ルール作成と適用 | 既存のコーディング規約をBob Rulesとして明文化し、AIの実装をチームの開発標準に沿って安定させる方法を学ぶ。 |
| シナリオ③【EXTEND（機能拡張）】 カスタムモード作成 & 機能追加 | MCPで外部の最新ドキュメントを参照させながら、専用モードでタスクを自動分解し高速に機能を実装させる方法を学ぶ。 |
| シナリオ④【REVIEW（レビュー）】 Skills 作成 & コードレビュー | 一度作ったレビューSkillを繰り返し呼び出し、開発標準とセキュリティ観点に基づくレビュー〜修正を再現性高く回す方法を学ぶ。 |
| オプション Bob Shell | IDEを離れて対話・ヘッドレスの両方でBobを呼び出し、CI/CDなど自動化パイプラインに組み込む方法を学ぶ。 |

---

### シナリオ①【ONBOARD（導入）】 AGENTS.md 作成

**あらすじ**
Bob IDEで `inventory-app` を開き、Agent mode で `/init` を実行するだけで、Bob がプロジェクト内のファイルを読み取り、プロジェクト全体を理解するための `AGENTS.md` と、モードごと（Agent / Plan / Ask）のコンテキストファイルを自動生成します。この理解は以降のすべての会話に引き継がれるため、実装に入る前の「土台づくり」を1コマンドで済ませる体験です。

### シナリオ②【GOVERN（規約適用）】 コーディング規約から、カスタム・ルール作成と適用

**あらすじ**
社内に既にある `python-coding-rules.txt`（PEP 8の抜粋）をBobに読み込ませ、`.bob/rules/` 配下の正式なRulesドキュメントとして整理・生成します。生成したRulesに従って既存の `app.py` / `data_manager.py` を実際に修正させることで、明文化した規約がそのままBobの実装方針として効いてくることを確認します。

### シナリオ③【EXTEND（機能拡張）】 カスタムモード作成 & 機能追加

**あらすじ**
MCP（context7）を設定してFlask・pandasの公式ドキュメントをリアルタイム参照できるようにしたうえで、`/create-mode` でその技術スタックに特化したカスタムモード（実装モード）を作成します。作成したモードに切り替えて「カテゴリ別フィルタリング」機能の追加を指示すると、Bobが要件整理から実装までのタスクを自動分解し、複数ファイルを並列に処理しながら実装を進めます。

### シナリオ④【REVIEW（レビュー）】 Skills 作成 & コードレビュー

**あらすじ**
`/create-skill` で、`.bob/rules/` の開発標準に加えてセキュリティ観点（認証情報の露出、SQLインジェクション、XSSなど）も含めたコードレビューSkill「review」を作成します。新しいタスクで `/review` と1コマンド打つだけで作業ディレクトリ全体がレビューされ、重要度（Critical〜Low）別に報告された指摘のうち優先度の高いものをBobに修正依頼するところまでを体験します。

### オプション Bob Shell

**あらすじ**
Bob IDEのコマンドパレットからBob ShellをインストールしてCLIから起動し、対話セッションで質問できることを確認します。続けてAPI keyを取得し、`bob --prompt "/review"` のようにヘッドレスで1回のプロンプトを処理させる使い方を体験します。シナリオ④で作った `/review` スキルをIDEを開かずに実行できることから、CI/CDのパイプラインに組み込んで自動レビューを回す運用イメージにつなげます。
